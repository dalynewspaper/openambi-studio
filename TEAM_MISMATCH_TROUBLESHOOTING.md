# Team Mismatch Troubleshooting Guide

## The Problem

You have multiple teams in Xcode:
- ✅ **Brian Daly** (or your name) - Paid Apple Developer Program ($99/year)
- ❌ **Brian Daly (Personal Team)** - Free Personal Team (limited capabilities)

**Sign in with Apple and Recording capabilities don't work in TestFlight because:**
1. The App ID might be registered under the wrong team
2. Capabilities might be enabled under Personal Team instead of Developer Program
3. Provisioning profiles might be generated by the wrong team

## How to Identify the Issue

### In Xcode:
1. Go to **Signing & Capabilities** tab
2. Check the **Team** dropdown
3. If you see "(Personal Team)" selected, that's the problem!

### In Developer Portal:
1. Go to [developer.apple.com/account](https://developer.apple.com/account/)
2. Check top right corner
3. If it says "Free" or "Personal Team", you're on the wrong account
4. You need to sign in with your **paid Developer Program** account

### Check App ID Ownership:
1. Developer Portal → **Certificates, Identifiers & Profiles**
2. Click **Identifiers** → Your App ID
3. Look at the page header - which team does it show?
4. If it shows "Personal Team", that's the problem!

## The Fix

### Option 1: Use Existing App ID (If it's under correct team)

1. **Verify App ID is under correct team:**
   - Developer Portal → Identifiers → Your App ID
   - Should show your paid Developer Program team name

2. **Enable capabilities under correct team:**
   - In the App ID, enable "Sign in with Apple"
   - Enable any other needed capabilities
   - Click **Save**

3. **Update Xcode:**
   - Xcode → Signing & Capabilities
   - Select **paid Developer Program team** (NOT Personal Team)
   - Add capabilities if needed
   - Xcode will regenerate provisioning profile

### Option 2: Create New App ID (If existing is under wrong team)

**If your App ID is under Personal Team, you MUST create a new one under Developer Program:**

1. **Create new App ID in Developer Portal:**
   - Sign in with **paid Developer Program** account
   - Developer Portal → Identifiers → **+** → App IDs
   - Register new App ID (e.g., `co.fourthquarterstudio.openambi`)
   - **Enable capabilities:**
     - ✅ Sign in with Apple
     - ✅ Background Modes (Audio)
   - Click **Continue** → **Register**

2. **Update Xcode:**
   - General tab → Change Bundle Identifier to match new App ID
   - Signing & Capabilities → Select **paid Developer Program team**
   - Add capabilities (they should match Developer Portal)
   - Xcode will create new provisioning profile

3. **Update App Store Connect:**
   - If app already exists, you may need to create a new app listing
   - Or contact Apple Support to transfer/update

## Step-by-Step Verification

### 1. Verify Your Developer Program Status

**In Developer Portal:**
- Go to [developer.apple.com/account](https://developer.apple.com/account/)
- Top right should show your paid membership
- If it shows "Free" or "Personal Team", you need to enroll

**In Xcode:**
- Xcode → Settings → Accounts
- Your account should show "Apple Developer Program" membership
- If it only shows "Free", you need to enroll

### 2. Verify Team Selection in Xcode

**For each target (app, widget extension, etc.):**
1. Select target
2. Signing & Capabilities tab
3. Team dropdown
4. **Select paid Developer Program team** (NOT Personal Team)
5. Verify no errors appear

### 3. Verify App ID Configuration

**In Developer Portal:**
1. Certificates, Identifiers & Profiles → Identifiers
2. Find your App ID
3. Check which team owns it (should be paid Developer Program)
4. Verify capabilities are enabled:
   - Sign in with Apple ✅
   - Background Modes ✅
   - Any others you need ✅

### 4. Verify Provisioning Profile

**In Xcode:**
- Signing & Capabilities → Provisioning Profile
- Should say "Xcode Managed Profile" for your Developer Program team
- Should NOT mention "Personal Team"

**If you see errors:**
- Delete the capability
- Switch to correct team
- Re-add the capability
- Xcode will regenerate provisioning profile

## Common Error Messages

### "No profiles for 'co.fourthquarterstudio.openambi' were found"
**Cause:** App ID doesn't exist under selected team
**Fix:** Create App ID in Developer Portal under correct team

### "Sign in with Apple capability requires a provisioning profile"
**Cause:** Capability enabled but App ID doesn't have it, or wrong team
**Fix:** Enable in Developer Portal under correct team, then update Xcode

### "The app ID cannot be registered to your team"
**Cause:** App ID already exists under different team
**Fix:** Use different Bundle ID, or contact Apple Support to transfer

### "Provisioning profile doesn't include the Sign in with Apple capability"
**Cause:** Provisioning profile generated before capability was enabled
**Fix:** Delete capability in Xcode, switch to correct team, re-add capability

## Quick Diagnostic Commands

**Check your team ID:**
- In Xcode, the team ID appears in project.pbxproj as `DEVELOPMENT_TEAM`
- Compare with Developer Portal team ID

**Check Bundle ID:**
- Xcode → General → Bundle Identifier
- Must match App ID in Developer Portal exactly

**Check Entitlements:**
- File: `openambi-studio.entitlements`
- Should have `com.apple.developer.applesignin` key
- This is automatically added when capability is enabled
